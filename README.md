# Editor

A multi-user collaborative code editor with real-time synchronization. Built with Python, this editor allows multiple users to edit code simultaneously.

## Features

- Real-time collaborative editing
- Multi-user support with live sync
- Simple client-server architecture

## Project Structure

- server.py — WebSocket server for managing connections and synchronizing edits
- client.py — Client interface for connecting and editing
- editor.py — Core editor logic

## Tech Stack

- Python
- WebSockets
